# TalentLens AI

An explainable, local-first Resume Screening, Job Matching and Skill Gap Analysis System built for a CSE final-year project.

## Features

- Upload PDF, DOCX, or TXT resumes
- Extract contact details, education, experience hints, and skills
- Create and manage job descriptions
- Rank candidates against jobs with TF-IDF cosine similarity and a transparent skill score
- Show matched and missing skills, gaps, and tailored learning recommendations
- Includes seeded demo jobs and candidate profiles

## Run locally

See the root project hand-off instructions or run the backend and frontend commands described below.

The product is intentionally self-contained: it uses SQLite and local NLP-style matching, with no paid AI service.
